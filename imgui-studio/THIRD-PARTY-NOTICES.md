## Where Each One Ends Up

Two files carry other people's code. `app/engine.js` is a single-file emscripten
build with the wasm binary embedded in it. `app/vendor/editor.bundle.js` is an
esbuild bundle of CodeMirror 6 and Lezer, generated by `scripts/build_vendor.mjs`
and committed the way `app/imguidocs.js` is.

Dear ImGui - vendored as a git submodule at `engine/imgui`, pinned to v1.92.1,
unpatched. Compiled into `app/engine.js`. `app/imguidocs.js` is generated from
the vendored `imgui.h` and carries function declarations and doc comments from
it, so it is a derivative of Dear ImGui too.

JSON for Modern C++ - vendored as a single header at `engine/json.hpp`, version
3.11.3. Compiled into `app/engine.js`.

Emscripten - not vendored. `emcc` emits its JavaScript runtime support code
directly into `app/engine.js` at build time.

CodeMirror 6 and Lezer - installed from npm and bundled into
`app/vendor/editor.bundle.js`. The bundle's own banner lists every package and
version that went into it, and `scripts/build_vendor.mjs` refuses to write a
bundle carrying a package this file does not name.

Note: `playwright-core` and `esbuild` are development dependencies. They run the
test suite and build the vendor bundle respectively, neither is part of the app,
and neither is redistributed, so neither is listed here.
