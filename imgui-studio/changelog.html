0.2.0 2026-08-02

The canvas remembers where you were

  • Pan and zoom are saved with the project instead of being thrown away. A reload comes back where you left it, and each project tab keeps its own position rather than every switch resetting to the origin.
  • Share links and both export files carry the view, but only when it isn't the plain 0,0 at 100% the app opens at anyway. A panel designed out in negative space now opens on the panel rather than on empty ground.
  • A view arriving from a link or a file is range-checked before it's applied, so a corrupt one can't strand the canvas somewhere with nothing on it.

Templates have categories

  • The Templates panel draws one folding section per category. The eight worked examples are filed under Examples, and anything you save lands in Yours.
  • Twelve new templates under Widget Gallery, one per widget category, holding one of every type in the catalog between them. A unit check asserts that coverage, so a new widget can't end up with no example anywhere.
  • File a template by dragging it into another section, or from its right-click menu. New Category… makes one up. Categories stick across a reload, built-in templates included.
  • A new templates page, in the Help menu, documenting the lot.

Fixes

  • Opening a menu with the mouse no longer arrives with its first entry already highlighted. That highlight is the keyboard cursor and it was being set on every open, so File sat with New Project lit and nothing took it off. Opened from the keyboard it still starts on the first row, so Enter has something to run.
  • Alt+Tab away from the editor and back no longer paints a cyan focus ring around the canvas. The browser re-focuses the canvas when the window returns, with no input behind it, and the ring was being recomputed from the Alt keystroke.
  • The preview window can no longer be resized by ImGui's own edge or corner grip while you're editing. Nothing carried that size into the document except from the bottom-right corner of an explicitly sized window, so edge drags and auto-sized windows snapped back and the gesture read as ignored. The selection handles do write to the document. In interactive mode the grip is live, and leaving interactive mode puts the size back to what the document says.

Generated code

  • Every condition the generator emits is braced now. A popup's trigger and a modal's Close button were the last three one-liners without braces. The parser reads both forms, since hand-written code arrives either way.

0.1.0 2026-07-29

The first build. A visual builder for Dear ImGui layouts that generates C++ and reads it back:

  • A canvas running the real Dear ImGui compiled to WebAssembly, not a mock of it, with an edit mode and a hold-to-test interactive mode.
  • The full widget catalog, a property inspector, a hierarchy, multi-select, marquee selection, inline label editing, guides, rulers and a world origin that reaches into negative coordinates.
  • A code pane that goes both ways: the generated C++ round-trips back into the document, so hand-written edits survive.
  • Projects, templates, JSON import and export, share links that carry a document in the URL, rebindable keys, a command palette, and themes for the editor and the generated code.
Versions before 0.2.0 predate this page, so 0.1.0 is summarized rather than itemized. The commit history is the record for that stretch.
