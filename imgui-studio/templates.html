Templates, and the Categories They Live In

The Templates panel is the second thing most people click and the last thing anyone reads about. This page is the whole of it: what a template is, what the shipped ones are for, and how to file your own.

What a Template Is

A template is a document you keep around to stamp out again. A project is the thing you're working on. That's the whole distinction, and it's why the two live in separate panels: closing a project asks you first, and a template just sits there until you use it.

There are four ways to spend one, and they do genuinely different things.

GestureWhat happens
Click the name, or the ＋ button Inserts its widgets into the nearest container that can hold them, walking up from whatever you have selected. They arrive wrapped in a Function container named after the template, so the generated C++ calls a function instead of inlining a wall of widgets. Ungroup it like any other container if you'd rather have the widgets loose.
Drag it onto the canvas The same insert, aimed at the drop point rather than at the selection. The drop indicator shows where it will land.
Right-click, Apply Here Replaces the whole document with the template. It asks first when there's anything to lose, and Ctrl+Z puts it back.
Right-click, Open as Project Opens it as a new project tab, leaving what you were doing alone. This is the safe one.

A template that carries several windows brings all of them, as windows, rather than folding them into one container. Debug Overlay is the example to look at: its button opens a second window by title, so a version that arrived as a single container would point at nothing.

Inserting into a document with no window at all adds the template's own window instead of refusing. That's why Blank Window works as the first thing a new user clicks.

Categories

Every template is filed under a category, and the panel draws one folding section per category. Click a section header to fold it. The fold state is remembered per category, and it's kept apart from the palette's own sections, so folding Text in the palette doesn't fold anything here.

Three categories ship with the app:

  • Examples holds the eight worked examples. Each one is a real panel built to show a specific feature working.
  • Widget Gallery holds the twelve specimen sheets, one per widget category.
  • Yours is where anything you save or import lands.

A category is just a name, so you aren't limited to those three. There are two ways to change where a template sits:

  • Drag the row into another section. A drop lands it in that category at the position you dropped it, which is the same gesture that reorders within a section.
  • Right-click it. The menu carries a Move to entry for every other category that currently exists, plus New Category…, which turns the row into a text field. Enter commits and Esc means never mind.

Categories with nothing in them stop being sections. Invent one, move your last template out of it, and it's gone. The shipped three always sort first and in the order above, and anything you invent sorts alphabetically after them.

Filing works on the built-in templates too, and it sticks. Categories are replayed by template name on load, the same way the panel's manual ordering is, so a built-in you moved into Yours is still there after a reload rather than snapping back to where it shipped.

The Widget Gallery

Twelve templates, one per widget category, holding one of every widget in the catalog between them. All 73 widget types appear somewhere in there, and a unit check asserts exactly that, so a widget added to the catalog without a home in the gallery turns the test suite red.

These are specimens rather than scenes. Everything sits at its catalog default with a plain label, so what you see is what the widget does before anyone has done anything to it. Insert one, click a widget in it, and the Properties panel tells you what you can change. The Code pane tells you what it compiles to.

Two of them are shaped by rules ImGui itself enforces. Menus is a whole window rather than a list of widgets, because a menu bar is only legal directly on a window that carries the MenuBar flag. Containers nests a Text widget inside each container it shows, because an empty container has nothing to draw and would look like the template forgot it.

The gallery is also the fastest way to answer "does this tool support X". Fold Examples, open Widget Gallery, and read the twelve names.

Saving Your Own

File → Save as Template takes the whole document, including every window in it, and files it under Yours. The name comes from the first window's title, with a number appended if that name is taken.

Your own templates carry a ✕ on their row and a Delete entry in the context menu. The built-in ones don't, because they're rebuilt from source on every load and deleting one would only last until the next reload.

Drag a row up or down to reorder it. Manual order is saved by name and replayed on load, so a template you dragged to the top of a section stays at the top. A built-in added by a later version of the app that isn't in your saved order keeps its natural position rather than being ordered away.

Files, Sharing and Storage

Templates live in your browser's local storage, under the same origin as the editor. Only your own are stored: the built-ins are rebuilt from the app's source each load, and what's saved for them is where you filed them and where you dragged them.

  • Export in the panel's toolbar writes every custom template to one JSON file, categories included.
  • Right-click a single template and choose Export Template to write just that one.
  • Import reads either file back. Imported names that collide get a number appended rather than overwriting what you have.
  • File → Export Everything carries templates along with your projects, panel layout, themes, guides and the hotbar. That's the one to use when you're moving to another machine.

Template files have a kind of their own, so importing a template file can't be mistaken for opening a document. Drop the wrong file on the app and it tells you what it was instead of quietly doing nothing.

Share links carry a document, not a template. To hand someone a template, export it and send the file, or send them a share link and let them use File → Save as Template on what arrives.
