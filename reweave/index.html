// THE FULL CIRCUIT

Web, UMG, and Slate —
all connected.

Reweave is designed around a single intermediate representation — WUIR — that can feed any emitter. HTML→UMG is the first direction. UMG→HTML export and Slate C++ output are planned, making the whole system a two-way bridge between the web and Unreal's native UI layers.

◈ UMG Widget Blueprint output live
⟺ planned

◉ WUIR — Web UI Intermediate Representation

All three formats share the same IR. Capture once, emit anywhere — UMG today, Slate or other engines later, without re-capturing the source.

// CONVERSION MAP

What crosses the boundary.

Reweave is layout and widget scaffolding — not a runtime web renderer. Know what converts cleanly and what gets approximated today.

✓ Converts cleanly

  • DOM tree structure
  • Flex and box layout
  • Absolute positioning (from rects)
  • Colors — sRGB → linear
  • Typography: family, size, weight
  • Opacity and visibility
  • 2D CSS transforms
  • Button, input, checkbox, select
  • Progress bars
  • Repeated lists → UListView
  • Images → imported textures

≈ Approximated

  • CSS gradients (baked to texture)
  • CSS grid fr units
  • Border radius (nearest UMG match)
  • Box shadow (partial)
  • Inline SVG (rasterized)
  • Animations on transform, opacity, color, visibility → UWidgetAnimation
  • Easing curves (cubic-bezier baked to keyframes)
  • Filter/shadow animation (via material param track)
